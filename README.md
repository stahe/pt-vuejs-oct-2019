[Vue.js] é um framework de JavaScript. Apresentámos a linguagem JavaScript no documento anterior: [Introdução ao ECMAScript 6](https://stahe.github.io/pt-ecmascript6-oct-2019/).

Não iremos realizar um estudo exaustivo do framework [Vue.js]. Apenas apresentaremos os conceitos que serão utilizados mais adiante ao escrever um cliente [Vue.js] para a versão JSON da versão 14 do servidor de cálculo de impostos (ver [Tutoriais e cursos de PHP 7](https://stahe.github.io/en-ecmascript6-oct-2019/)).

## Metodologia

Os scripts deste documento estão comentados e a sua saída é reproduzida na consola. São fornecidas explicações adicionais quando necessário.
